# GTU BE Computer Syllabus Archive

A permanent archive of Gujarat Technological University (GTU) Bachelor of Engineering, Computer Engineering (branch 07) teaching schemes: every subject code, subject name, category, lecture/tutorial/practical hours, credits and marks breakup, for every scheme and semester available on the official GTU syllabus portal.

Archived from the official portal (old26.gtu.ac.in/Syllabus/Syllabus.aspx) starting 2026-11-12, so the record survives even if the portal changes or removes old schemes.

## PDF backup

Offline copies of the syllabus PDFs are kept in a Google Drive folder, organised by scheme. The Drive link will be added here when the PDF backup is complete.

## Columns

L = Lectures, T = Tutorial, P = Practical, PBL = Project Based Learning, E = External theory marks, M = Internal assessment, I = Internal viva/submission, V = External viva, Total = total marks. Values are exactly as shown on the GTU portal.

## Note

Syllabus PDF links in the scheme pages point to GTU's official syllabus PDF for that subject code; the PDF backup section above links to the offline copies.
